The Instruction Cycle

How a Microprocessor Executes Instructions · FETCH → DECODE → EXECUTE → WRITEBACK
01 Fetch Get the instruction
Program Counter (PC) holds the memory address of the next instruction. Sent to RAM via the address bus. RAM returns binary data via the data bus into the Instruction Register (IR). PC then increments.
PC → Address Bus → RAM → Data Bus → IR
02 Decode Interpret the instruction
Control Unit (CU) examines bits in the IR. Instruction splits into opcode (what to do) and operands (what to use). For ADD R1, R2, R3 — CU routes R2 & R3 to the ALU, tells it to prepare for addition.
CU · Opcode Decoder · Operand Routing
03 Execute Do the computation
ALU receives values from registers. Inside, transistors form adder circuits from logic gates (half-adders, full-adders). Addition happens in 1 clock cycle. Result emerges — e.g., 5 + 7 = 12. ALU also sets flag bits.
ALU · Adder Circuit · Logic Gates
04 Writeback Save the result
Result (12) is written back into destination Register R1. CU marks instruction as complete. CPU loops back to Stage 1 (Fetch) for the next instruction. The cycle repeats billions of times.
Destination Register · Instruction Complete
Cycle repeats for every instruction

① FETCH · Details

  • PC: Holds address of next instruction
  • Address Bus: Sends address to RAM
  • Data Bus: Returns instruction data
  • IR: Stores current instruction
  • PC = PC + 4: Points to next instruction

② DECODE · Details

  • Opcode: What operation to perform
  • Operands: What data to use
  • CU: Activates appropriate circuits
  • Routes data to the ALU
  • Prepares for computation

③ EXECUTE · Details

  • ALU: Performs math & logic
  • Transistors form adder circuits
  • Half-adders + full-adders = addition
  • Result + flag bits (overflow, zero)
  • 1 clock cycle (or a few)

④ WRITEBACK · Details

  • Result saved to Register
  • CU marks instruction complete
  • Loop back to FETCH
  • Next instruction begins
  • Continues until program halts
⚙️
Modern Pipelining: While Instruction A is at Writeback, Instruction B is at Execute, Instruction C is at Decode, and Instruction D is being Fetched — like an assembly line. 3 GHz CPU = 3 billion cycles per second.
