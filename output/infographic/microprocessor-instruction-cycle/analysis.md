## Main Topic
A step-by-step explanation of how a microprocessor executes instructions through the 4-stage Instruction Cycle: Fetch → Decode → Execute → Writeback.

## Learning Objectives
After viewing this infographic, the viewer should understand:
1. The four stages of the microprocessor instruction cycle and what happens in each
2. How components like the PC, IR, Control Unit, ALU, and registers work together
3. How the cycle repeats to execute a full program

## Key Data Points (Verbatim)
- "3 GHz CPU ticks 3 billion times per second"
- "A single instruction might take 1 to ~30 cycles depending on complexity"
- "Modern CPUs use pipelining — while one instruction is executing, the next is already being decoded"
- "Transistors are made of silicon (sand), doped with impurities to control conductivity"
