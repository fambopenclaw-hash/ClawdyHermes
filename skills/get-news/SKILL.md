# Get News

## Overview

The get-news skill retrieves and summarizes the latest news from four key categories: Malaysia local news, global news, Iran-US war developments, and technology/AI news. It ensures fresh content (within 24 hours) and presents it in a clear, categorized format with detailed summaries. All output is in English (user preference: no Malay translations).

## When to Use This Skill

Trigger the skill when the user requests news updates or summaries in any of these four domains.

## Capabilities

The skill supports fetching news for the following categories:

1. **Malaysia Local News**
   - Focus: National and regional events within Malaysia
   - RSS feed: `https://news.google.com/rss/search?q=Malaysia+news&hl=en-MY&gl=MY&ceid=MY:en`

2. **Global News**
   - Focus: Major world events and international developments
   - RSS feed: `https://news.google.com/rss/search?q=global+news&hl=en-US&gl=US&ceid=US:en`
   - ⚠️ **Known pitfall**: The query `q=global+news` matches the Canadian TV network named "Global News", which can dominate the top 20 results. You MUST filter out results from the "Global News" source (and similar network names like "Global News Canada") before picking your top 5 items, or the category will be filled with Canadian local/cable-TV stories. If after filtering you get too few items, use a fallback query: `q=world+news+international` or `q=latest+world+events`.
   - ⚠️ **Fallback query pitfall**: The fallback `q=world+news+international` is itself noisy — it returns press releases (city/state government PR, university announcements), sports coverage (NHL, World Cup, baseball tournaments), gaming/entertainment fluff, and travel-industry puff pieces alongside legitimate news. You MUST filter these out too. See `references/global-news-fallback-filtering.md` for the full list of noise patterns and a Python filtering heuristic. After aggressive filtering, if you still have < 3 items, try `q=latest+world+events+geopolitics`.

3. **Iran-US War**
   - Focus: Latest developments in the conflict between Iran and the United States
   - RSS feed: `https://news.google.com/rss/search?q=Iran+US+conflict&hl=en-US&gl=US&ceid=US:en`

4. **Technology & AI**
   - Focus: Recent advancements, product releases, and research in technology and artificial intelligence
   - RSS feed: `https://news.google.com/rss/search?q=artificial+intelligence+AI+technology&hl=en-US&gl=US&ceid=US:en`

## How to Use

When the user requests news:

1. Identify which categories are needed. If none are specified, fetch all four.
2. Fetch RSS feeds in parallel using `terminal` with `curl`.
3. Parse RSS XML to extract titles (skip the first "Google News" item) and descriptions.
   - **Clean titles**: Remove source suffixes (e.g., if title contains " - ", take the first part before the first " - ").
   - **Clean descriptions**: Strip HTML tags (e.g., `re.sub(r'<[^>]+>', '', description)`), decode HTML entities (e.g., `&nbsp;` → space, `&amp;` → `&`, `&quot;` → `"`).
4. Limit results to `count` items per category (default: 5).
5. Generate a **lengthy, detailed summary (3-4 sentences)** for each article by extracting core information through deep analysis.
6. Format each result as:
   {number}. ***{title}***
   {detailed_summary}

### Formatting Preferences
- Titles: ***Bold and Italic*** (format as `***Title***`)
- Summaries: Plain text only, no italics/bold formatting, no "Summary:" prefix.
- Language: Always output in English (no Malay translations — user preference).
- Emojis: Include relevant emojis sparingly for visual appeal.
- Category headers: Use flag emojis (🇲🇾 for Malaysia, 🌍 for Global, 🇮🇷🇺🇸 for Iran-US, 💻 for Tech/AI).

### Optional Parameters

- `count`: Number of results to fetch per category (default: 5)
- `specific_categories`: A list of categories to fetch (if user specifies). Options: `["malaysia", "global", "iran_us", "tech_ai"]`

## Implementation Notes

### Google News RSS Description Limitation
The `<description>` field in Google News RSS items contains **only the title text wrapped in an anchor tag** followed by the source name — it is NOT an article preview or summary. When extracting descriptions, you will get the title text repeated (e.g., `"Man charged with murder of daughter&nbsp;&nbsp;Daily Express Malaysia"`). Do not treat this as useful article content. The 3-4 sentence **detailed summaries must be generated by the LLM from the title alone** using general knowledge and reasonable inference about what the article likely covers. If the title is too vague to infer a meaningful summary, denote "Summary unavailable."

### XML Parsing
Google News RSS feeds sometimes contain bare `&` characters (not valid XML entities) inside descriptions. Use regex-based parsing (re.findall on `<item>` blocks) rather than ElementTree, which will error on malformed XML. When cleaning descriptions, decode HTML entities FIRST (`html.unescape()`) then strip HTML tags — doing it in the opposite order misses entity-encoded tags like `&lt;a href=`.

### Error Handling

| Scenario                          | Action                                                                 |
|-----------------------------------|------------------------------------------------------------------------|
| Summary generation fails          | Provide title; denote "Summary unavailable."                          |
